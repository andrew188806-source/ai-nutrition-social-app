# Phase 2W-E0 Recommendation Trust Policy

After allergy, safety, availability, and user-exclusion hard filters, candidates rank by:

1. Exact menu item with current nutrition verification.
2. Unverified item belonging to a currently nutrition-badged restaurant/branch.
3. Admin-confirmed existence.
4. Community support from at least two independent verified users.
5. Single-user registered provisional target.

Tier 2 does not receive an item badge. Tier 5 is excluded from general recommendations. Partner affiliation is valid only for a canonical relationship. Trust never overrides a failed allergy/safety filter, unavailability, or an explicit user exclusion. Stable target ID breaks otherwise equal ordering.
