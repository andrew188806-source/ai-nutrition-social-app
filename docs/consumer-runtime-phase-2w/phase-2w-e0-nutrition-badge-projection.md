# Phase 2W-E0 Nutrition Badge Projection

- Consumer surfaces project only current nutrition verification, not internal catalog, partner, or review state.
- A menu-item badge appears only for the exact valid verified item.
- A restaurant/branch badge appears when at least one current menu item in that scope has valid nutrition verification. It never means every item is verified.
- AI-estimated, unverified, pending, invalidated, expired, or conflicting records show no nutrition badge.
- Branch scope is the default. Shared verification requires confirmed common recipe, portion, and SOP.
- Recipe, portion, ingredient, or cooking-method change, expiry, or conflicting evidence invalidates verification and disables the badge.
