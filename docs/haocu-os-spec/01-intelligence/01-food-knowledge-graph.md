# Food Knowledge Graph

Status: Draft v1.0
Priority: P0 Core Intelligence

## Purpose

Food Knowledge Graph（FKG）是 Haocu OS 的核心知識模型。

它描述世界中有哪些物件、物件彼此如何連結、AI 如何理解這些關係。

## Core Entities

- User
- Meal
- Restaurant
- Dish
- Dining
- Nutrition
- Taste
- Compatibility
- Trust
- Food Provider
- Community Card
- Meal Buddy Card

## Core Relationships

- User consumes Meal
- Meal contains Dish
- Dish served by Restaurant
- Meal occurs at Restaurant
- User participates Dining
- Dining includes User
- Restaurant provides Dish
- Dish has Nutrition
- User has Taste
- User predicts Compatibility
- User earns Trust

## MVP Scope

P0: User, Meal, Restaurant, Dish, Dining, Nutrition, Taste, Compatibility, Trust, Community Card, Meal Buddy Card, Relationship Recording.
