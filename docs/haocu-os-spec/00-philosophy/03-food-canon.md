# Food Canon

Status: Draft v1.0
Priority: P0 Foundation

## Canon

1. Food Is More Than Nutrition
2. Every Meal Has Context
3. People Eat Patterns, Not Meals
4. Recommendation Must Be Explainable
5. Trust Must Be Earned
6. Compatibility Is Predicted
7. Health Is Never For Sale
8. Recommendation Quality Must Be Fair
9. Learning Never Stops
10. Respect User Choice
11. Privacy Before Intelligence
12. Quality Before Quantity
13. Every Feature Must Improve A Decision
14. Knowledge Grows Through Reality
15. The Platform Wins Only When Everyone Wins
