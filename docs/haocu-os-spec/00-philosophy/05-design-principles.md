# Design Principles

Status: Draft v1.0

## Principles

1. Reduce Decision Fatigue
2. One Primary Action
3. Progressive Disclosure
4. Explain Before Asking
5. Reduce Repetition
6. Action Creates Learning
7. Always Show Progress
8. Keep The User In Control
9. Consistency
10. Fast Feedback
11. Simple First
12. AI Is An Assistant
