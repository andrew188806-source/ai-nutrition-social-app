# 09 Frontend

Version: v2.0 Alpha 4  
Updated: 2026-07-08  
Owner: Frontend Lead / Product Engineering

This folder defines frontend implementation for mobile, restaurant web, and admin web.

## Frontend Goals

- Keep the app clean, warm, tidy, and demo-friendly.
- Make core flows short and obvious.
- Avoid duplicate actions and confusing tabs.
- Keep AI analysis, Meal Buddy, restaurant, chat, and group table flows connected through consistent data.
- Make free vs premium visible without making free users feel punished.

## Frontend Rule

Every visible action should either complete an obvious task or move the user to the next expected context. Do not create pages that make users wonder whether something happened.
