# 00 Repository Core

## Alpha 10 Status

This core section records the status, assumptions, decisions, conventions, changelog, risk boundaries, and versioning notes for Haocu OS Master Repository v2.0 Alpha 10.

Alpha 10 is a final editorial consolidation / repository freeze. It preserves sections `00` through `27` and adds role-specific final handoff files at the repository root.

## Core Files

- `PROJECT_STATUS.md` — current repository completion and Alpha 10 freeze status.
- `CHANGELOG.md` — version history through Alpha 10.
- `CURRENT_DECISIONS.md` — current decision record.
- `ROADMAP.md` — roadmap context.
- `ASSUMPTIONS.md` — baseline assumptions.
- `KNOWN_LIMITATIONS.md` — known limitations.
- `RISK_REGISTER.md` — core risk register.
- `DOCUMENT_CONVENTION.md` — document rules.
- `NAMING_STANDARD.md` — naming rules.
- `GLOSSARY.md` — glossary.
- `VERSIONING.md` — versioning notes.
- `CTO_ONBOARDING.md` and `ENGINEER_ONBOARDING.md` — technical onboarding.
