## Key Decisions Reinforced

- MVP core loop: Analyze → Save → Understand → Recommend → Optional Social.
- Haocu is not a medical product.
- Today intake and nutrition report must use the same meal record collection.
- Meal-buddy and group-table flows must use unified user/social card data.
- Premium expands depth and capacity; free remains useful.
- Restaurant nutrition and paid visibility require review boundaries.
- Multi-photo meal UI is deferred while data fields remain future-ready.
