# Alpha 7B Release Notes

## Release Summary

Alpha 7B adds the Professional Review Pack. This transforms the repository from an engineering and planning package into a professional-review-ready package.

## Why This Matters

Before Haocu is used for public launch, real user data, crowdfunding, investor outreach, patent disclosure, or restaurant pilots, the project needs targeted review by qualified professionals. Alpha 7B makes that review efficient by separating legal, privacy, AI/nutrition, security, finance, fundraising, restaurant, ESG, insurance, and cross-border questions.

## Major Additions

- Reviewer routing map.
- Legal/IP and patent review briefs.
- Privacy/data protection review brief.
- Terms and consumer-platform review brief.
- AI/nutrition/health claims review brief.
- Security technical review brief.
- Finance/accounting/tax review brief.
- Fundraising/securities review brief.
- Restaurant commercial review brief.
- ESG/supply-chain review brief.
- Insurance/liability review brief.
- Taiwan/US cross-border review brief.
- Professional questionnaires.
- Reviewer outreach emails.
- Decision log template.
- Red flag matrix.
- Structured review question data.

## Boundary

Alpha 7B is not legal, financial, tax, securities, patent, insurance, nutrition, or medical advice. It prepares the materials for professional review.
