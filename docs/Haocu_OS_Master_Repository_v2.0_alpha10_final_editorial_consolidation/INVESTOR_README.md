## Investor-Safe Interpretation

The repository describes a planned and partially demo-oriented startup operating system for Haocu, an AI nutrition and food-social app concept with restaurant-partner expansion potential. Materials are organized to show product logic, MVP scope, engineering readiness, business narrative, fundraising preparation, legal/IP review needs, and investor diligence structure.

## Evidence Label Standard

All investor-facing claims should use one of the following labels:

| Label | Meaning |
|---|---|
| Planned | Designed or intended but not yet demonstrated or validated. |
| Demo | Demonstrated in a prototype, mock flow, script, screenshot, or recorded walkthrough. |
| Pilot | Tested or discussed in a limited real-world pilot or partner/user setting. |
| Live | Operating in production with real users, partners, transactions, or usage. |
| Verified | Supported by documented third-party, legal, financial, technical, or operational evidence. |

## Key Investor Questions This Repository Can Support

- What is Haocu and what problem does it solve?
- What is the MVP and what is intentionally out of scope?
- How does AI analysis connect to meal records, restaurant recommendations, and Meal Buddy social features?
- What makes the data and personalization loop defensible over time?
- What can be built first by engineers?
- What must be reviewed by legal/IP/privacy/nutrition professionals?
- What evidence is still planned versus demo, pilot, live, or verified?

## Key Investor Caution

Do not interpret mock data, demo scripts, planned pilots, draft LOIs, unreviewed claims, or projected metrics as live traction. Use `DEMO_MOCK_DATA_DISCLOSURE.md` and `CLAIMS_AND_RISK_REVIEW.md` before relying on any external claim.
