## Change Control After Freeze

Use this sequence for future changes:

1. Record the proposed change outside the frozen package.
2. Classify it as product, engineering, legal, investor, restaurant, evidence, or operations.
3. Identify source files affected.
4. Decide whether the change is a correction, evidence update, professional-review update, or new scope.
5. If it belongs in the repository, open a new version and document the reason.
