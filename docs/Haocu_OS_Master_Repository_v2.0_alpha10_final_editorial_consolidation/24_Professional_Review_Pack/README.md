## Purpose

This folder converts the Haocu OS Master Repository into a professional-review package. It is designed for attorneys, patent counsel, privacy/data consultants, security reviewers, accountants, tax advisors, fundraising advisors, insurance brokers, and restaurant/commercial advisors.

Alpha 7B does not replace professional advice. It creates a structured packet so external reviewers can quickly understand the product, locate the right repository sections, identify issues, and return decisions that can be translated into engineering, legal, finance, or business tasks.

## How To Use

1. Start with `001_PROFESSIONAL_REVIEW_OVERVIEW.md`.
2. Select the reviewer-specific brief.
3. Attach only the relevant repository sections to avoid overwhelming reviewers.
4. Ask reviewers to return decisions using `016_REVIEW_DECISION_LOG_TEMPLATE.md`.
5. Convert decisions into engineering, compliance, legal, finance, or pitch tasks.
6. Do not publish fundraising, claims, patent, privacy, or partnership materials until critical review items are closed.
