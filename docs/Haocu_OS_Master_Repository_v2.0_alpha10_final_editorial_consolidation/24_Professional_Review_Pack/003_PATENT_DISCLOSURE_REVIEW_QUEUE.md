# Patent Disclosure Review Queue

## Purpose

This file organizes patent-review topics for a patent attorney. It is not a patent application. It is an invention-disclosure and patentability review queue.

## Candidate Invention Areas

### 1. Personalized Taste Memory + Nutrition Recommendation

Potential novelty angle:

- A system that combines private personal meal feedback, hidden taste ratings, nutrition objectives, restaurant menu structures, and similarity between users to recommend meals and restaurants that are closer to the user's actual taste instead of public average ratings.

Questions for patent counsel:

- Is this protectable as a technical method rather than a business idea?
- What specific data structures, ranking steps, model updates, or feedback loops should be emphasized?
- What prior-art search terms should be used?

### 2. Meal-Photo Correction Loop

Potential novelty angle:

- A food-recognition workflow where AI returns candidates, user correction is stored as structured feedback, and future restaurant/menu/personalized recommendation accuracy is improved.

Questions:

- Is the correction loop too obvious?
- Does restaurant menu grounding improve patentability?
- Should claims focus on multimodal candidate generation, user correction, or downstream recommendation?

### 3. Meal Buddy Matching Based on Nutrition and Taste Context

Potential novelty angle:

- Matching users for meal companionship using meal intent, eating time, restaurant/menu context, taste similarity, nutrition goals, social-card preferences, and premium/free constraints.

Questions:

- Is this likely considered abstract social matching?
- What technical implementation details could strengthen patentability?
- Should this remain trade secret instead of patent disclosure?

### 4. Calorie / Guilt Sharing System

Potential novelty angle:

- A post-meal shared responsibility and social accountability mechanism for group eating, including meal completion status, shared allocation, manual import, and non-medical behavior feedback.

Questions:

- Is this too much like gamification?
- Are there patentable data-processing mechanics?
- Should this be excluded to reduce health-risk exposure?

### 5. Restaurant Data Flywheel

Potential novelty angle:

- Restaurant menu data improves AI recognition; user corrections improve restaurant menu and recommendation confidence; restaurant verified entries receive ranking and trust treatment.

Questions:

- Can this be protected as an operational data flywheel?
- Should the focus be on database-first AI grounding and confidence scoring?

## Patent Attorney Review Output Needed

- Patentability score by topic.
- Prior-art search strategy.
- Recommended filing order.
- Taiwan first filing vs US/PCT strategy.
- What must not be publicly disclosed before filing.
- What should be kept as trade secret.
- Required inventor/assignee structure.
- Budget range and timeline.
- Risks of founder-owned IP licensed to company.
