## Evidence Upgrade Path

| From | To | Required Action |
|---|---|---|
| Planned | Demo | Build/show the flow and capture screenshots/video. |
| Demo | Pilot | Let real users/restaurants test it and record results. |
| Pilot | Live | Launch to real users with repeatable analytics. |
| Live | Verified | Export data, review by third party, or attach signed/commercial evidence. |

## Investor-Safe Claim Review

Before sending a claim externally, ask:

1. Is the claim true today?
2. Is the evidence level clearly labeled?
3. Is the source document included or available?
4. Does the claim require legal, finance, health, privacy, or patent review?
5. Would the statement still be accurate if quoted by an investor later?
