# Investor Response Tracker Template

> Use: Track exactly what investors asked and how Haocu responded. This prevents inconsistent answers across calls.

## Response Quality Levels

| Level | Meaning |
|---|---|
| Draft | Founder has a draft answer, not externally validated. |
| Clean | Answer is suitable for investor conversations. |
| Evidence-Linked | Answer links to demo, pilot, document, or metric evidence. |
| Professionally Reviewed | Legal/finance/privacy/technical reviewer has checked sensitive content. |

## Rules

1. If two investors ask the same question, update the master Q&A rather than inventing new wording.
2. If an answer touches legal, securities, tax, medical, privacy, or patent matters, mark it for professional review.
3. If a claim requires evidence, add it to the demo or pilot tracker.
4. If an investor misunderstands the product category, update the short memo and pitch opening.
