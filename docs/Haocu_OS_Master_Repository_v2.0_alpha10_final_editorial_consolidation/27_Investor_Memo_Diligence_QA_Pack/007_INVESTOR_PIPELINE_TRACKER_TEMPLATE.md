# Investor Pipeline Tracker Template

> Use: Master fundraising CRM. Keep raw private notes internal. Share only cleaned summaries externally.

## Pipeline Stages

| Stage | Meaning | Exit Criteria |
|---|---|---|
| Target | Potential investor identified. | Contact method selected. |
| Intro Requested | Warm intro requested or cold email prepared. | Intro sent / email sent. |
| Intro Sent | Investor has received a first message. | Reply or no-response follow-up. |
| First Call | Meeting scheduled or completed. | Investor requests more, passes, or asks for diligence. |
| Diligence | Investor is reviewing materials. | Clear yes/no/later or partner process. |
| Soft Commit | Verbal interest, amount not final. | Terms / timeline / evidence gap clarified. |
| Commit | Confirmed participation subject to docs. | Legal/funding process begins. |
| Pass | Investor declines. | Feedback captured. |
| Later | Investor wants update after milestone. | Next update date set. |

## Tracker Columns

| Column | Description |
|---|---|
| investor_name | Individual or firm name. |
| contact_name | Primary person. |
| type | Angel / VC / Accelerator / Advisor / Strategic / Platform / Restaurant-connected. |
| source | Who introduced or how sourced. |
| stage | Use the stages above. |
| check_size_range | Approximate if known. |
| thesis_fit | Consumer AI / Food / Restaurant / Social / Taiwan / ESG / Other. |
| last_contact_date | Latest interaction. |
| next_step | Specific next action. |
| next_step_date | Date for follow-up. |
| key_question | Main investor concern. |
| evidence_requested | Demo / metrics / pilot / legal / finance / tech. |
| sent_materials | What was shared. |
| confidentiality_level | Intro / Clean Data Room / Deeper Diligence / NDA. |
| outcome | Open / Pass / Later / Soft Commit / Commit. |
| notes | Internal notes only. |

## Review Cadence

- Update after every investor interaction.
- Review all open investors twice per week during active fundraising.
- Move stale investors to Later or Pass rather than keeping fake momentum.
- Track repeated questions; repeated objections should update `024_INVESTOR_OBJECTION_RESPONSE_BANK.md`.
