# Pilot / LOI / Restaurant Interest Tracker

> Use: Track restaurant, partner, advisor, and pilot interest. Do not overstate interest. A conversation is not an LOI.

## Interest Levels

| Level | Meaning |
|---|---|
| Lead | Potential restaurant/partner identified. |
| Contacted | Outreach sent. |
| Meeting Held | Conversation completed. |
| Interested | Expressed interest but no concrete commitment. |
| Pilot Candidate | Has agreed to discuss pilot details. |
| Pilot Confirmed | Email/LOI/agreement confirms pilot. |
| Active Pilot | Data or usage collection has started. |
| Completed Pilot | Pilot finished and evidence summarized. |
| Not Interested | Declined or unresponsive. |

## Investor-Safe Language

| Actual Status | Say This | Do Not Say This |
|---|---|---|
| One casual conversation | "We have begun restaurant discovery conversations." | "We have restaurant partners." |
| Email interest | "A restaurant has expressed interest in exploring a pilot." | "Signed pilot." |
| LOI signed | "We have a non-binding LOI / pilot confirmation." | "Guaranteed revenue." |
| Active pilot | "Pilot is active with [scope]." | "Scaled restaurant adoption." |
