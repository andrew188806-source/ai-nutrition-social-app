# 025 Metrics And Traction Plan

> Repository Status: Haocu OS Master Repository v2.0 Alpha 7C.  
> Purpose: Fundraising / investor / accelerator / partner communication package.  
> Boundary: Draft material only. All valuation, securities, legal, tax, nutrition, patent, privacy, and financial claims require professional review before external publication.

## Purpose

Define what evidence Haocu should collect before asking investors to believe the larger story.

## North Star Candidate

Weekly corrected meal records per active user.

Reason: correction means the user did more than take a photo; they trusted the product enough to improve the data.

## Activation Metrics

- signup completion
- onboarding completion
- first meal analysis started
- first analysis saved
- correction completed
- Today Intake viewed
- first recommendation viewed

## Engagement Metrics

- weekly active users
- meals saved per week
- correction rate
- diary return rate
- recommendation engagement
- restaurant card clicks
- rating/feedback completion

## Social Metrics

- Meal Buddy cards created
- invite sent
- invite accepted
- chat opened
- group table created/joined
- report/block incidents
- anonymous vs verified usage

## Restaurant Metrics

- restaurants contacted
- pilot meetings booked
- restaurant profiles created
- menu items structured
- dish cards completed
- QR page interest
- restaurant feedback score

## Monetization Metrics

- Premium feature interest
- preorder/crowdfunding pledge conversion
- willingness-to-pay survey results
- restaurant package interest
- pilot continuation intent

## Investor Milestone Evidence

| Milestone | Evidence |
|---|---|
| MVP works | demo + core event data |
| Users care | retention and repeated meal records |
| Recommendations matter | recommendation engagement and feedback |
| Social adds value | Meal Buddy creation and invite conversion |
| Restaurants care | pilot completion and partner feedback |
| Revenue plausible | Premium/crowdfunding/restaurant willingness signal |

## Reporting Cadence

- Weekly internal metrics review during pilot.
- Biweekly advisor update.
- Monthly investor update once fundraising begins.

## Avoid Vanity Metrics

Do not overemphasize downloads, page views, or social likes without activation and retention evidence.
