# 016 Team Hiring Plan

> Repository Status: Haocu OS Master Repository v2.0 Alpha 7C.  
> Purpose: Fundraising / investor / accelerator / partner communication package.  
> Boundary: Draft material only. All valuation, securities, legal, tax, nutrition, patent, privacy, and financial claims require professional review before external publication.

## Current Need

Haocu’s next phase requires execution. The repository is broad; the team should stay small and focused until MVP validation.

## Founder Role

Founder responsibilities:

- product direction
- user interviews
- restaurant outreach
- demo storytelling
- investor/advisor communication
- final decisions on scope and prioritization
- mascot/brand direction

## Critical Early Roles

| Role | Timing | Why Needed | Notes |
|---|---|---|---|
| Engineering Lead / CTO Advisor | Immediate | Convert Alpha 7A into implementation discipline | Could be advisor/contract before full-time |
| Mobile Engineer | Immediate/P0 | Expo React Native MVP flow | Must respect clean UI and i18n |
| Backend/Supabase Engineer | Immediate/P0 | Auth, DB, storage, RLS, API/data layer | Core to real MVP |
| Product Designer | P1 | Simplify flows and demo clarity | Should prevent clutter/duplicate controls |
| AI/Data Engineer | P1 | Analysis pipeline, recommendation, cost control | Can start part-time/advisory |
| QA / Release Support | P1 | Regression and demo reliability | May be contractor initially |
| Restaurant Ops / BD | P1/P2 | Pilot partner onboarding | Founder-led first, hire after signal |
| Legal/IP/Privacy Counsel | Review-based | External review | Not employee initially |
| Finance/Accounting Advisor | Review-based | Funding model and compliance | Not employee initially |

## Hiring Philosophy

- Do not give equity casually to contractors.
- Equity should be tied to long-term commitment, role clarity, vesting, and legal documents.
- Use milestone-based contracts where possible before product-market signal.
- Avoid hiring for future phases before MVP works.

## First 90-Day Team Plan

### Days 1–14

- Engineering lead reviews Alpha 7A.
- Mobile/backend foundation starts.
- Founder prepares pilot users and restaurants.
- Legal/privacy review begins.

### Days 15–45

- Core MVP loop stabilizes.
- Pilot metrics instrumentation begins.
- Restaurant intake pilot starts.
- Pitch deck and crowdfunding assets refined.

### Days 46–90

- Closed pilot results reviewed.
- Premium and restaurant package assumptions tested.
- Data room updated.
- Fundraising/crowdfunding decision made.

## Team Risk

The main team risk is trying to build too many surfaces at once. The hiring plan must protect the MVP loop: analysis, correction, diary, recommendation, restaurant card, Meal Buddy.
