## Core Narrative

Haocu is a Taiwan-first AI food recommendation and optional social dining platform for outside eaters. It starts with AI meal analysis and user correction, builds private taste and nutrition memory, recommends what to eat next, and optionally helps users find Meal Buddies or group tables around real food intent. Restaurants contribute structured menu data and benefit from more relevant discovery.
