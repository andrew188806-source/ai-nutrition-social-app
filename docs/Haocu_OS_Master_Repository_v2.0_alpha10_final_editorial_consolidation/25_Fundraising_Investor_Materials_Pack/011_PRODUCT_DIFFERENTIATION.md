## Positioning

Haocu is not competing on one feature. It is combining food memory, recommendation, local restaurant data, and optional social dining into one loop.

## Differentiation Matrix

| Category | Common Product | Gap | Haocu Advantage |
|---|---|---|---|
| AI food recognition | Identify food from image | Can be wrong and one-time | User correction converts guesses into memory |
| Calorie tracker | Nutrition log | High friction and shame risk | Informational summary plus recommendation |
| Restaurant review app | Public ratings | Generic and crowd-biased | Taste-fit recommendation based on private history |
| Social dining app | Profiles and matching | Low intent and safety concerns | Meal-intent card with anonymity/verification choices |
| Restaurant ad product | Pay for visibility | Trust risk | Transparent partner and data workflow |
| Food diary | History | Passive record | Diary feeds future recommendation |

## Core Differentiators

### 1. Correction-first AI

Haocu treats user correction as an asset, not an error.

### 2. Private taste memory

Recommendations are based on what the user actually ate, corrected, rated, and preferred.

### 3. Taiwan local-food context

The MVP can encode local restaurant and outside-eating patterns rather than generic global food categories.

### 4. Meal-intent social layer

Users connect around an actual meal plan, not abstract profile browsing.

### 5. Restaurant data loop

Restaurants are not only advertisers. They are structured menu-data partners.

## Copyable vs Harder-To-Copy

| Easy To Copy | Harder To Copy |
|---|---|
| Meal photo upload button | Corrected user-specific food memory over time |
| Generic nutrition estimate | Restaurant/menu graph plus user correction |
| Matching screen | Safe meal-intent social workflow and trust history |
| Mascot visuals | Brand + user identity + community + reward loop |
| Landing page claims | Pilot data and repeated behavior metrics |

## Investor Message

Haocu’s moat must be built through execution. The repository defines the loop; the MVP must prove the data compounds.
