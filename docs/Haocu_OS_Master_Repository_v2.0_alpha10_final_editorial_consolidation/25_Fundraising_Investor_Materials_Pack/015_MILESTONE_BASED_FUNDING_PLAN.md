# 015 Milestone-Based Funding Plan

> Repository Status: Haocu OS Master Repository v2.0 Alpha 7C.  
> Purpose: Fundraising / investor / accelerator / partner communication package.  
> Boundary: Draft material only. All valuation, securities, legal, tax, nutrition, patent, privacy, and financial claims require professional review before external publication.

## Why Milestone-Based

At this stage, Haocu should raise around proof points, not broad promises. The investor question should be: what evidence will this funding produce?

## Milestone Plan

| Milestone | Target Evidence | Primary Work |
|---|---|---|
| M0 Repository Ready | Alpha 7A/7B/7C complete | planning, backlog, review, fundraising pack |
| M1 Demo Stable | reliable 3-minute demo | typecheck, UI cleanup, data sync, demo seed |
| M2 MVP Core Loop | users can analyze, correct, save, receive recommendation | mobile/backend/AI/data implementation |
| M3 Closed Pilot | real users complete core flows | onboarding, interviews, analytics, feedback |
| M4 Restaurant Pilot | structured menu data from early restaurants | partner outreach, intake, data workflow |
| M5 Review Cleared | legal/privacy/claims/fundraising review decisions logged | Alpha 7B question queue resolved |
| M6 Crowdfunding Ready | campaign assets and supporter list ready | one-pager, video script, packages, landing page |
| M7 Next Round Ready | data room contains metrics and pilot evidence | investor memo, deck, metrics, risks, roadmap |

## Funding Tranche Logic

### Tranche A — Build / Review

Purpose: stabilize MVP and complete professional review.

Evidence expected:

- demo path stable
- core data model implemented
- privacy/terms/health-claims review started
- initial restaurant list created

### Tranche B — Pilot / Crowdfunding

Purpose: prove repeated user behavior and prepare public campaign.

Evidence expected:

- pilot users onboarded
- first restaurant data collected
- Premium interest tested
- campaign packages reviewed

### Tranche C — Scale / Next Round

Purpose: expand beyond first pilot with metrics.

Evidence expected:

- retention signal
- recommendation usefulness signal
- restaurant partner signal
- monetization signal

## Investor Communication

Use this format:

“We are raising to reach Milestone M3/M4/M6. At that point, we expect to show a stable MVP, closed pilot data, early restaurant partner evidence, reviewed legal/privacy boundaries, and crowdfunding readiness.”
