# 014 Use Of Funds

> Repository Status: Haocu OS Master Repository v2.0 Alpha 7C.  
> Purpose: Fundraising / investor / accelerator / partner communication package.  
> Boundary: Draft material only. All valuation, securities, legal, tax, nutrition, patent, privacy, and financial claims require professional review before external publication.

## Principle

Use-of-funds should be milestone-based. Do not present exact percentages externally until finance review confirms the raise size, runway, hiring plan, and accounting treatment.

## Core Buckets

| Bucket | Purpose | Examples |
|---|---|---|
| Engineering | Build and stabilize MVP | mobile, backend, Supabase, admin, QA, release |
| AI / Data | Meal analysis and recommendation | model orchestration, data schema, correction loop, cost monitoring |
| Design / Product | Demo-ready UX and product clarity | UI cleanup, flows, copy, prototype testing |
| Restaurant Pilot | Onboard early partners | intake, menu data, dish cards, partner feedback |
| Legal / Compliance / IP | Reduce external-use risk | privacy, terms, patent/trademark, health claims, crowdfunding review |
| Growth / Crowdfunding | Demand validation | landing page, video, campaign assets, ads test, community ops |
| Operations | Company setup and runway | accounting, admin, tools, insurance review |
| Contingency | Avoid running out of cash before milestone | bug fixes, delays, unexpected review costs |

## Suggested Internal Allocation Logic

Do not use this as a public final budget without review.

- Engineering and product execution should dominate early spend.
- Legal/compliance review is non-optional before public launch or fundraising publication.
- Growth spend should be staged after the demo and campaign story are strong.
- Restaurant pilot spend should be small but structured.
- Mascot goods should be cost-controlled and not consume MVP runway.

## Funding Milestones Paid For

A milestone-based raise should pay for:

1. Demo stabilization.
2. MVP backend/data migration.
3. Closed pilot.
4. Restaurant pilot.
5. Professional review completion.
6. Crowdfunding readiness.
7. Investor data room cleanup.

## Use-Of-Funds Acceptance Criteria

- Every budget line maps to a milestone.
- No large spend depends on unvalidated assumptions.
- Legal/compliance review is included.
- Founder runway is explicit if included.
- Contingency is visible.
- Reward fulfillment costs are separated from product development.
