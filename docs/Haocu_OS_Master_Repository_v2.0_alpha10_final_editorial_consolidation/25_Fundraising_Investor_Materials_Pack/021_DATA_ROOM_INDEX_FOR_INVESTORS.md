# 021 Data Room Index For Investors

> Repository Status: Haocu OS Master Repository v2.0 Alpha 7C.  
> Purpose: Fundraising / investor / accelerator / partner communication package.  
> Boundary: Draft material only. All valuation, securities, legal, tax, nutrition, patent, privacy, and financial claims require professional review before external publication.

## Purpose

This index defines what should be included in a clean investor data room after Alpha 7C. Do not expose the entire working repository to every investor. Prepare a clean, curated version.

## Sharing Rules

- First call: one-pager + deck + demo video only.
- Serious interest: curated data room.
- Before terms: finance/legal documents and professional review notes.
- Sensitive IP: share only after counsel review and appropriate confidentiality approach.

## Data Room Cleanliness Rule

Investors should see a clear story, not every draft. Keep internal scratch, unresolved brainstorming, and unreviewed legal/patent details out of the first shared folder.
