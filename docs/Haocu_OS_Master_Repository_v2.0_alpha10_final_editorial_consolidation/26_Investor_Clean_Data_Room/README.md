# Investor Data Room README

> Repository Status: Haocu OS Master Repository v2.0 Alpha 8.  
> Purpose: Clean investor / advisor / accelerator / restaurant-partner data room.  
> Boundary: External-readable summary only. Not legal, tax, accounting, securities, nutrition, medical, patent, privacy, or investment advice. Sensitive internal drafts and unreviewed details are intentionally excluded.

## What This Folder Is

`26_Investor_Clean_Data_Room` is the external-facing, controlled-sharing layer of the Haocu OS Master Repository. It does not replace the internal repository. It gives investors, accelerator reviewers, strategic advisors, and restaurant partners a clean path to understand the company without exposing every internal draft, engineering detail, legal hypothesis, or unresolved risk note.

## Data Room Principle

External readers should see a clear, confident, honest story:

- what Haocu is building
- why the problem matters
- what is in MVP versus later phases
- how the company may make money
- what evidence the next funding should produce
- what risks are known and how they are being mitigated
- what still requires professional review

They should not receive raw internal scratchpads, unresolved patent details, unreviewed legal conclusions, detailed security implementation notes, private valuation math, contractor negotiations, or unfiltered founder brainstorming.

## Recommended Sharing Levels

| Sharing Level | Audience | Include |
|---|---|---|
| Level 1 Intro | Warm intro, first call, accelerator screen | Founder brief, company/product overview, one-pager/deck from Section 25. |
| Level 2 Serious Review | Angel, advisor, platform reviewer | This full Section 26 clean data room. |
| Level 3 Pre-Term / Professional Review | Investor doing deeper diligence, counsel, finance reviewer | Selected Section 23/24/25 files after redaction and NDA/appropriate confidentiality approach where needed. |
| Internal Only | Founder, core team, retained reviewers | Full master repository and raw working drafts. |
