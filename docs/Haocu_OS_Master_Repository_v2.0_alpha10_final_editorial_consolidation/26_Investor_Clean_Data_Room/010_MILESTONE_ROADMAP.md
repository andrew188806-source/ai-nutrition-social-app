# 010 Milestone Roadmap

> Repository Status: Haocu OS Master Repository v2.0 Alpha 8.  
> Purpose: Clean investor / advisor / accelerator / restaurant-partner data room.  
> Boundary: External-readable summary only. Not legal, tax, accounting, securities, nutrition, medical, patent, privacy, or investment advice. Sensitive internal drafts and unreviewed details are intentionally excluded.

## Roadmap Logic

Haocu’s roadmap should be communicated through proof milestones, not feature accumulation. Each stage should create evidence that reduces investor, product, technical, or market risk.

## Milestone Roadmap

| Milestone | Goal | Evidence |
|---|---|---|
| M0 Repository Prepared | Structured product/build/review/fundraising plan exists | Alpha 7A/7B/7C/8 complete. |
| M1 Demo Stable | Demonstrate core user loop clearly | 3-minute demo works, screenshots/video ready, UI readable. |
| M2 MVP Build | Implement core consumer loop | Analyze/correct/save/recommend flow; basic social and restaurant surfaces. |
| M3 Closed Pilot | Test behavior with real users | meal records, return usage, correction behavior, feedback interviews. |
| M4 Restaurant Pilot | Validate partner data workflow | early restaurants, dish/menu intake, restaurant feedback. |
| M5 Professional Review Decisions | Reduce external/legal/compliance risk | privacy, terms, claims, fundraising, IP review decision log. |
| M6 Crowdfunding Ready | Validate demand and launch story | landing page, campaign assets, package economics, prelaunch list. |
| M7 Public Validation | Generate market signal | crowdfunding results, acquisition learning, user/partner evidence. |
| M8 Next Round Ready | Prepare stronger fundraising | updated data room with metrics, pilot evidence, roadmap, budget. |

## Product Roadmap By Layer

| Layer | Near-Term | Later |
|---|---|---|
| Consumer | AI meal analysis, correction, diary, recommendation | deeper personalization, family/household expansion. |
| Social | Meal Buddy cards, invite/chat, group table basics | events, richer trust/safety, community loops. |
| Restaurant | cards, dish data, partner intake | dashboards, analytics, dynamic offers. |
| AI/Data | database-first, correction loop, recommendation foundation | taste embeddings, similar-user recommendations, deeper model evaluation. |
| Business | Premium/crowdfunding/restaurant pilot | B2B supply-chain, ESG, household plans. |

## Review Gates

Before each external milestone, confirm:

- demo does not overclaim unbuilt functions
- privacy/terms/claims language is current
- investor materials match the latest product scope
- financial assumptions are not presented as audited facts
- restaurant claims do not imply guaranteed traffic
- IP status is described as a review process, not as guaranteed defensibility

## Investor Takeaway

The roadmap is staged to turn Haocu from a structured concept into a tested product and partner ecosystem. The near-term focus is MVP evidence; future phases remain upside, not current funding assumptions.
