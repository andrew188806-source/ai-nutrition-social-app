# Investor Demo Script

Phase 1 supports a clickable skeleton for the future 3-minute story:

1. User opens the mobile app.
2. User enters mock login.
3. User reaches meal photo placeholder.
4. User continues to mock AI analysis.
5. User views meal log placeholder.
6. User views next-meal recommendation placeholder.
7. User opens social discovery preview.
8. User views verified restaurant recommendation placeholder.
9. User reviews data permission settings.
10. Restaurant and admin dashboards show supporting business and governance surfaces.
