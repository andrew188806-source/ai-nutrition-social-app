# 智慧財產權歸屬（IP Ownership）

> **分類** `IP_PATENT` · **狀態** `CANONICAL_CURRENT` · **最後對帳** 2026-09-26 · **機密** `PRIVATE_INTERNAL` · `NOT_FOR_VENDOR_EXPORT_BY_DEFAULT` · 入口：[MASTER_HANDOFF_INDEX](../00_INDEX/MASTER_HANDOFF_INDEX.md)

## 先分清楚兩件完全不同的事

| 名稱 | 是什麼 | 正式文件 |
| --- | --- | --- |
| **專利（legal patent）** | 法律上的專利申請與權利歸屬 | 本分類（`07_IP_PATENT/`） |
| **IP Codex／吉祥物圖鑑** | App 內的系列圖鑑程式架構（技術文件 `docs/ip-codex-scale-system.md`） | [OTHER_DEFERRED_FEATURES](../10_POST_MVP/OTHER_DEFERRED_FEATURES.md)（實體商品部分）、[CONSUMER_PRODUCT](../01_PRODUCT/CONSUMER_PRODUCT.md) |
| **授權外部 IP 的品牌規則** | 外部授權 IP 不得成為 TastKind 的品牌身分（ODR-026） | [BUSINESS_MODEL](../08_BUSINESS_MONETIZATION/BUSINESS_MODEL.md) |

**不要把技術上的「IP Codex」程式文件當成法律上的專利歸屬證據。**

## 專利歸屬現況

- 專利申請目前**由創辦人個人持有**。
- 申請階段的專業費用由創辦人**個人支付**（成本責任見 [IP_COST_RESPONSIBILITY](IP_COST_RESPONSIBILITY.md)）。
- 公司目前**不是**專利申請人；未來的授權、轉讓或公司取得方式見 [LICENSING_TRANSFER_OPTIONS](LICENSING_TRANSFER_OPTIONS.md)（開放框架，尚未決定）。
