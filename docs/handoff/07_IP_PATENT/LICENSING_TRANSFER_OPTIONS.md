# 授權／轉讓選項（Licensing / Transfer Options）

> **分類** `IP_PATENT` · **狀態** `CURRENT_DIRECTION` / `NEEDS_PLANNER_RECONCILIATION` / `LEGAL_TAX_ADVICE_REQUIRED` · **最後對帳** 2026-09-26 · **機密** `PRIVATE_INTERNAL` · `NOT_FOR_VENDOR_EXPORT_BY_DEFAULT` · 入口：[MASTER_HANDOFF_INDEX](../00_INDEX/MASTER_HANDOFF_INDEX.md)

> 以下是**開放框架**。沒有任何一項是凍結決定、已簽約條款或法律意見。

## 目前方向

- 專利**獲准後**，再評估授權、轉讓或由公司取得。
- 未來國際擴展的成本，可能在**未來的協議**下由公司負擔（見 [IP_COST_RESPONSIBILITY](IP_COST_RESPONSIBILITY.md)）。

## 討論過的框架元素（全部 `OPEN`）

| 元素 | 狀態 |
| --- | --- |
| 權利金授權（royalty licensing） | `CURRENT_DIRECTION`，細節未定 |
| 權利金上限（royalty cap） | `OPEN` |
| 公司出資的未來地區擴展 | `CURRENT_DIRECTION`，需協議 |
| 公司支付擴展／維持費用期間的延續性 | `OPEN` |
| 創辦人離開時的處理 | `OPEN` |
| 公司優先購買權／買斷 | `OPEN` |
| 估值方式、歷史成本抵扣 | `OPEN`；`LEGAL_TAX_ADVICE_REQUIRED` |
| 技術作價／以股權處理 | `OPEN`；`LEGAL_TAX_ADVICE_REQUIRED` |

## 刻意**不**記錄（不得自行補上）

最終權利金比例、最終終止權、最終估值方法、稅務處理、條款可執行性。
