這是交接文件的**主入口**。任何主要主題都能在「本索引 → 類別正式文件」**兩步之內**找到。

## 導覽規則

1. **一個主題只有一個正式所在（canonical home）。** 其他文件只連結過去，不複製內容。
2. 每份文件開頭標明：分類、狀態、最後對帳日、機密等級。
3. 陳述一律區分：`IMPLEMENTED`、`LIVE_ACCEPTED`（指 Development）、`LOCAL_ACCEPTED`、`PLANNED`、`POST_MVP`、`HYPOTHESIS`、`EXTERNAL_RECHECK_REQUIRED`、`OPEN`。
4. 舊文件**不搬移、不刪除**；它們的狀態在 [SOURCE_OF_TRUTH_MAP](SOURCE_OF_TRUTH_MAP.md) 與 `docs/DOCUMENT_STATUS_INDEX.md` 中標記。
5. 找主題 → [SOURCE_OF_TRUTH_MAP](SOURCE_OF_TRUTH_MAP.md)；找決定狀態 → [DECISION_STATUS_INDEX](DECISION_STATUS_INDEX.md)。

## 機密分級與外包匯出

- 整個 `docs/handoff/` 預設為 `PRIVATE_INTERNAL` · `NOT_FOR_VENDOR_EXPORT_BY_DEFAULT`（與 `governance/` 相同規則）。
- `05_FINANCE`、`06_CORPORATE_LEGAL`、`07_IP_PATENT`、`08_BUSINESS_MONETIZATION`、`09_OPERATIONS_GTM`、`11_DECISION_REGISTERS` 與本索引**不得**匯出給外包工程團隊。
- `02_ENGINEERING`、`03_SECURITY_AUTHORITY`、`04_DEPLOYMENT_ENVIRONMENTS` 不含商業資料，經審閱後可提供給外部工程團隊。此預設待 Planner 確認（OD-19）。
- 本文件集不含任何密碼、連線字串、TOTP、token 或金鑰值。
