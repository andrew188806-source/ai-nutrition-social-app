# Final Handoff Checklist

## Purpose

Use this checklist before handing Alpha 10 to engineers, investors, lawyers, advisors, restaurant partners, or internal contributors.

## Universal Checklist

- [ ] Confirm recipient audience.
- [ ] Send the role-specific `*_READ_FIRST.md` file.
- [ ] Confirm whether the full repository is needed or only a curated subset.
- [ ] Remove unrelated internal notes if sharing externally.
- [ ] Check `CLAIMS_AND_RISK_REVIEW.md` for risky language.
- [ ] Check `DEMO_MOCK_DATA_DISCLOSURE.md` before showing demo screens or mock data.
- [ ] Confirm whether professional review is required before use.
- [ ] Record who received the package, date, version, and files shared.

## Engineer Handoff

- [ ] Send `ENGINEER_READ_FIRST.md`.
- [ ] Send `ENGINEER_HANDOFF_README.md`.
- [ ] Confirm MVP scope from `01_Product/005_MVP_SCOPE.md`.
- [ ] Confirm first sprint plan from `23_Engineering_Backlog_Pack`.
- [ ] Confirm mock/demo data separation.
- [ ] Confirm PRD-to-backlog mapping.
- [ ] Ask engineers to return implementation plan, risks, and first build estimate.

## Investor Handoff

- [ ] Send `INVESTOR_READ_FIRST.md`.
- [ ] Send `INVESTOR_README.md`.
- [ ] Prefer `26_Investor_Clean_Data_Room` before full repository.
- [ ] Use `27_Investor_Memo_Diligence_QA_Pack` for formal diligence.
- [ ] Label every claim as Planned, Demo, Pilot, Live, or Verified.
- [ ] Do not claim traction without evidence.
- [ ] Track responses in the Alpha 9 investor trackers.

## Legal / IP Handoff

- [ ] Send `LEGAL_READ_FIRST.md`.
- [ ] Send `LEGAL_IP_README.md`.
- [ ] Include `17_Legal_IP`, `14_Compliance`, and `24_Professional_Review_Pack`.
- [ ] Ask for redline, approval status, risk notes, and claim-language rules.
- [ ] Do not publish legal/IP/fundraising language until reviewed.

## Restaurant Partner Handoff

- [ ] Send `RESTAURANT_PARTNER_READ_FIRST.md`.
- [ ] Send `RESTAURANT_PARTNER_README.md`.
- [ ] Use restaurant-facing one-pagers, not full internal docs, for early conversations.
- [ ] Label pilot as planned unless confirmed.
- [ ] Track interest, meeting notes, and LOI status.

## Internal Team Handoff

- [ ] Send `INTERNAL_TEAM_READ_FIRST.md`.
- [ ] Confirm terminology standards.
- [ ] Confirm change-control process after freeze.
- [ ] Confirm no one overwrites Alpha 10 without a versioned update.

## Final Confirmation

- [ ] Repository version is Alpha 10.
- [ ] 00–27 sections are preserved.
- [ ] Final readme layer exists.
- [ ] Manifest and packaging docs are updated.
- [ ] ZIP export was tested.
