# Demo and Mock Data Disclosure

## Purpose

This file protects the repository from accidentally presenting mock/demo material as live traction, real users, verified AI performance, signed restaurant partnerships, or production usage.

## Disclosure Rule

Any demo, prototype, screenshot, scripted walkthrough, mock user, mock restaurant, mock meal, mock chat, mock group table, mock nutrition value, or staged investor demo must be labeled as mock/demo unless it is backed by live or verified evidence.

## Mock Data May Be Used For

- UI demonstration.
- PRD acceptance testing.
- Investor walkthroughs.
- Engineer QA.
- Restaurant pilot explanation.
- User-flow validation.
- Copywriting examples.

## Mock Data May Not Be Used To Claim

- Real active users.
- Real retention.
- Real revenue.
- Real restaurant partnerships.
- Real restaurant menu/nutrition verification.
- Real AI accuracy.
- Real social matching safety or behavior.
- Real product-market fit.

## Required Demo Label

Use a clear label in screenshots, decks, demo videos, and walkthroughs:

> Demo data shown for product walkthrough only. Not live user, restaurant, revenue, nutrition-verification, or traction data unless separately marked as verified evidence.

## Evidence Upgrade Path

| Current State | Upgrade Requirement |
|---|---|
| Mock user | Consent-backed user test or live account evidence. |
| Mock meal | Real uploaded meal record with permission and privacy controls. |
| Mock restaurant | Restaurant-approved menu or pilot data. |
| Mock nutrition | Reviewed data source, restaurant-provided information, or documented estimation method. |
| Mock chat/match | Real beta/pilot interaction with safety and consent review. |
| Mock metric | Analytics export or manually verified tracker. |
