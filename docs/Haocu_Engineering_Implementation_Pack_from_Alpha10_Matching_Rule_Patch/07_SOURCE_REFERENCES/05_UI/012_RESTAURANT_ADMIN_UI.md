# Restaurant Admin UI

## Purpose
Define restaurant-side UI for managing profile, menu, nutrition disclosure, and future promotional/ESG workflows.

## MVP Admin Sections

1. Restaurant profile.
2. Branch information.
3. Menu management.
4. Ingredient/portion fields.
5. Nutrition estimate/review status.
6. QR nutrition page preview.
7. Submission status.

## Menu Item Editor

Fields:

- dish name
- description
- price
- photo
- ingredients
- portion
- cooking method
- tags
- nutrition values or AI estimate request

## Nutrition Status Badges

- 未提供
- AI 估算
- 餐廳提供
- 平台審核中
- 已審核

## Restaurant Admin Principles

- Keep forms simple for busy restaurant operators.
- Allow draft save.
- Explain why nutrition fields matter.
- Do not force full nutrition completion for initial onboarding unless required by product phase.

## Acceptance Criteria

1. Restaurant can create/edit menu item.
2. Nutrition disclosure status is visible.
3. AI-estimated nutrition is not shown as verified.
4. Restaurant profile can be reviewed by admin.
5. QR nutrition preview can be generated from approved data.
