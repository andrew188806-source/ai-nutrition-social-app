# 05_UI README

## Purpose
This section defines Haocu’s UI system for mobile MVP, restaurant/admin surfaces, and demo readiness.

The design direction is **clean, warm, cute, demo-friendly, and visually uncluttered**. UI should prioritize clear hierarchy, spacious layout, reduced duplicate elements, and fast comprehension by non-technical viewers.

## Core UI Decisions

- Mobile first.
- Traditional Chinese user-facing copy.
- White/clean background with clear contrast.
- Avoid overusing green as primary brand color.
- AI analysis path should be direct and low-friction.
- Meal Buddy social identity must clearly distinguish anonymous mascot mode and Premium real-person mode.
- Home should show a simplified nutrition summary, not the full report.
- Search inputs and tabs should appear only where contextually needed.
