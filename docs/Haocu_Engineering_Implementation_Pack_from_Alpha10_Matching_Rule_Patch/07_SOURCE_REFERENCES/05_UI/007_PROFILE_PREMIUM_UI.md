# Profile and Premium UI

## Purpose
Define user profile, settings, Premium feature explanation, and identity upgrade surfaces.

## Profile Sections

1. Account/profile summary.
2. Social identity mode.
3. Food preferences.
4. Health goal mode.
5. Food diary / favorites shortcuts.
6. Premium status.
7. Settings and privacy.

## Anonymous Identity UI

Show:

- mascot avatar
- anonymous display label
- explanation that free users can use mascot identity

## Real-Person Premium Identity UI

Show:

- real avatar/photo upload
- verification status
- Premium unlock explanation
- privacy copy

Verification states:

- not verified
- pending
- verified
- rejected

## Premium Paywall Principles

Paywall should:

- explain concrete value
- show free vs Premium comparison
- avoid blocking core demo flows too early
- use warm copy, not pressure

## Premium Feature Examples

- more Meal Buddy card creation quota
- more candidate recommendations
- multi-select invites
- real-person social card
- extended diary/top records
- advanced health goal mode

## Health Goal Mode

Health goal UI should be positioned carefully:

- user-controlled
- estimate-based
- not medical advice
- professional review required before strong claims

## Acceptance Criteria

1. Free/Premium identity difference is clear.
2. Verification status is visible and consistent.
3. Paywall explains benefit, not just restriction.
4. Health goal copy avoids medical claims.
5. Profile settings include privacy and identity controls.
