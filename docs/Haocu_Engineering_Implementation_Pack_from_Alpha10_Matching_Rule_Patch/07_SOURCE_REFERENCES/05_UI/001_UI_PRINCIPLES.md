# UI Principles

## Design Direction
Haocu should feel like a warm, clean, modern food companion. It should not feel like a dense enterprise dashboard or a guilt-heavy dieting app.

Keywords:

- clean
- warm
- cute
- reliable
- light
- social but not noisy
- nutrition-aware but not judgmental

## Hierarchy Principles

1. One primary action per screen.
2. Avoid duplicate buttons with similar meaning.
3. Put contextual controls near the card they affect.
4. Keep full reports on detail pages, not home.
5. Use cards for meaningful content groups, not for every small text block.

## Visual Rules

- Prefer white or light background.
- Use high-contrast accent colors sparingly.
- Avoid green as the dominant brand color.
- Use warm food-friendly colors for CTAs.
- Keep shadows soft and subtle.
- Maintain generous spacing between sections.
- Use mascot/illustration for warmth, not clutter.

## Interaction Rules

- AI analysis should minimize steps.
- Correction should be easy and non-judgmental.
- Meal Buddy actions should clearly indicate whether they chat first or invite to eat.
- Premium locked states should explain value without blocking core demo flow.
- Date/time controls should appear near restaurant/meal card context, not hidden at the bottom.

## Tone Rules

Use friendly and practical copy:

- “幫你估算好了”
- “你可以再修正份量”
- “用這餐找飯友？”
- “今天蛋白質還可以再補一點”

Avoid shame:

- “你吃太多”
- “不健康”
- “不該吃”

## Demo Readability

For investor/family/restaurant demos:

- Main value should be visible within 3 seconds.
- Avoid hiding core flows behind deep tabs.
- Use meaningful fake data that looks realistic.
- Keep screen titles and card labels consistent.
- Ensure mascot/real-person distinction is obvious.

## Acceptance Criteria

1. Every primary screen has one clear main CTA.
2. Home is not overloaded with full reports.
3. Social identity mode is visually clear.
4. UI copy uses Traditional Chinese through i18n.
5. Screens remain readable in demo screenshots.
